# OWASP ASVS 5.0.0 Verification Checklist

Baseline: **OWASP Application Security Verification Standard (ASVS) 5.0.0 — Level 2**, with **Level 3** controls applied to authentication, authorization, administrator MFA, cryptography, and game integrity.

> Status legend: **Pass (Automated)** = verified by passing automated test/check in this repository; **Pass (Code + CI)** = implemented and covered by Worker/CI tests (see `SECURITY_TEST_REPORT.md` for local Windows `workerd` runtime note); **Partial / Operator** = requires operator configuration in Firebase/Cloudflare/GitHub; **Open (Residual)** = tracked residual risk requiring owner/security-reviewer acceptance.
